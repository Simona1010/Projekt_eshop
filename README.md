# Projekt_eshop
Projekt je zameraný na analýzu faktorov, ktoré ovplyvňujú ročné výdavky zákazníkov e-shopu.

Analýza bola vykonaná na datasete 500 zákazníkov a kombinuje spracovanie dát v R a podrobnejšiu štatistickú analýzu v SAS Enterprise Guide.
## Obsah projektu
- exploratórna analýza a vizualizácia dát,
- korelačná analýza,
- viacnásobná lineárna regresia,
- testovanie štatistickej významnosti premenných,
- výber premenných a diagnostika regresného modelu,
- vyhodnotenie predikčnej presnosti modelu.


## Použité nástroje
R, R Markdown, SAS Enterprise Guide, ggplot2, dplyr,tidyverse, lineárna regresia, štatistické testovanie, regresia
